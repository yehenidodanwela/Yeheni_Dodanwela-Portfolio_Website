Smart Campus API

Apr 2026 - Apr 2026

Built Smart Campus API, a fully RESTful backend system designed to manage smart campus environments, IoT sensors, and real time sensor readings. Developed using Java 11, JAX-RS (Jersey), and Apache Tomcat while following REST architectural principles and versioned API design practices.
Implemented room and sensor management, CRUD functionality, query filtering, HATEOAS based discovery endpoints, centralized logging, and robust exception handling using custom ExceptionMapper classes. The project also included professional API testing using Postman and thread-safe in-memory data storage for realistic smart campus simulations.
