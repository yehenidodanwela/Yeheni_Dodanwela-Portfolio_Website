CookMate Mobile Application

Oct 2025 - Mar 2026

Developed CookMate, a smart cooking companion mobile application designed to enhance the cooking experience using AI-powered recipe recommendations and IoT-based smart kitchen support. The application allows users to generate recipes based on available ingredients, dietary preferences, and allergy restrictions.
Implemented interactive cooking guidance with text-to-speech, voice alerts, timers, and audio controls to improve accessibility and usability. Integrated IoT functionality using Arduino and MQTT for real-time cooking temperature monitoring. The project included frontend and backend development, API integration, authentication systems, and deployment workflows using Render and Expo Go.
