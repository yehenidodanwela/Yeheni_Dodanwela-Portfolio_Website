Daily To Do

May 2026 - May 2026

Developed Daily To Do, a desktop productivity application designed to help users efficiently manage daily tasks, reminders, and recurring schedules through a clean and interactive interface. Built using Python and Tkinter, the application provides an intuitive task management experience with support for due dates, optional reminder times, repeat scheduling, and task completion tracking.
Implemented features such as drag-and-drop task reordering, calendar-based date selection, customizable color themes, reminder popups, and separate sections for active and completed tasks. The application uses local database storage for persistent task management and was packaged as a standalone Windows .exe application using PyInstaller for easy distribution and installation.

How to Use:

  • Download the release ZIP file from "Download App".
  • Extract the ZIP to any folder on your Windows PC.
  • Open the extracted folder and double click Daily To Do.exe.
  • If Windows shows a security warning, click More info and then Run anyway.
  • Add your tasks in the app and close it when you are done.
  • Your tasks are saved locally on your PC, so they will still be there next time you open the app.
